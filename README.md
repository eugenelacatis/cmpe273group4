CMPE 273 - Project Ideas due by Sep 14

Eugene Lacatis, Rosnita Dey, Robbie Tambunting, Lucas Nguyen

1. LLM observability/tracing platform (simplified respan.ai style), tracking latency, tokens, cost, errors, and retries per call, plus trace-level call trees, critical path, and parallel vs sequential ordering. Evals layer as a stretch goal.
2. Multiplayer game framework, a reusable matchmaking and real-time state sync backend that makes it easy to add multiplayer to a game. Simple example game included to show it off.
3. Payment processing platform (Stripe style), a FinTech system focused on the CP side of CAP theorem, consistency and correctness over availability. Early idea, needs more research.
